## 🛠️ How to Run the Code

You'll need a C++ compiler like **g++**.

```bash
# Compile
g++ filename.cpp -o output

# Run
./output          # Linux / macOS
output.exe        # Windows
```

Example:

```bash
g++ hello.cpp -o hello
./hello
```
